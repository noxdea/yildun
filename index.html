A terminal shell, not a web view.

Yildun keeps terminal behavior in Ruby and leaves SSH and multiplexing to dedicated tools.

Workspaces

Profiles, tabs, pane state, and configurable keymaps.

Navigation

Scrollback search, command history, and OSC 8 links.

Settings

JSONC configuration with fail-fast validation.

Tests

Scripted sessions with expected-screen comparison.

Run it without a TTY.

Headless mode prints the final terminal screen. Give CI a script, dimensions, timeout, and optional expected output file.

Interactive mode requires terminal input and output. Headless mode keeps the same session model available to automated checks.

gem install yildun
yildun --headless --command 'printf "hello\n"'
yildun --headless --script input.txt --expect screen.txt
